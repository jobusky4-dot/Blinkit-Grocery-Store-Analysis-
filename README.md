# Blinkit-Grocery-Store-Analysis-

## Project Overview
This project analyzes Blink it sales data using Excel and Power BI to identify sales trends, customer preferences, and outlet performance.
The Dataset was cleaned, transformed and Visualized to identify sales trends, outlet performance ,customer rating, and product insights
